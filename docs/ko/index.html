작동 방식

아이디어에서 게임까지 세 단계로

작업은 프로젝트 폴더에 저장됩니다. CDKit 런타임(cdkit.asi)이 게임 시작 시 활성화된 모드를 빌드하고 게임 자체 데이터 위에 불러옵니다.

프로젝트 만들기

폴더와 이름을 선택하세요. 이후의 모든 변경 사항이 그곳에 모여 백업, 버전 관리, 공유가 쉬워집니다.

변경 사항 만들기

월드 편집기, 퀘스트 디자이너, 아이템 편집기와 어시스턴트를 사용하세요. 무엇이든 실행 취소하고, 3D로 미리 보고, 플레이 모드에서 테스트할 수 있습니다.

플레이하고 공유하기

게임을 시작하세요. 런타임이 로딩 화면 뒤에서 활성화된 모드를 빌드합니다. 모드 관리자에서 모드를 끄거나, 다른 플레이어를 위해 하나의 패키지로 게시할 수 있습니다.

안전을 고려한 설계

게임은 언제든 되돌릴 수 있습니다

모드는 게임 자체 파일과 분리되어 있습니다. CDKit의 작은 런타임(cdkit.asi, ASI 로더가 불러옴)이 게임 시작 시 활성화된 모드를 빌드하고 실행 중인 게임에 보여 주므로 게임의 원본 파일은 하나도 바뀌지 않습니다. 모드 관리자에서 끈 모드는 다음 실행 때 사라지며, 여러 모드를 원하는 순서로 모든 충돌 목록과 함께 동시에 불러올 수 있습니다.

변경 사항은 복사본이 아닌 변경 내용 그대로 저장됩니다. CDKit이 게임 업데이트를 감지하면 런타임이 다음 실행 때 모드를 다시 빌드합니다.

질문

알아두면 좋은 점

CDKit은 무료인가요?

네. 다운로드하고 압축을 푼 다음 CDkit.exe 를 실행하세요. 계정도 설치 프로그램도 필요 없습니다.

게임이나 세이브 파일이 망가질 수 있나요?

게임의 원본 파일은 하나도 바뀌지 않습니다. 런타임 cdkit.asi(bin64의 ASI 로더가 불러옴)가 게임 시작 시 로딩 화면과 함께 활성화된 모드를 빌드하고 실행 중인 게임에 보여 줍니다. 모드 관리자에서 '이 모드 비활성화' 또는 '모든 모드 비활성화'를 누르면 모드가 꺼지고, 다음 실행부터 게임 자체 파일을 사용합니다. 플레이 모드는 저장을 막으므로 테스트하는 동안 저장 파일은 안전합니다.

무엇이 필요한가요?

Windows 10 또는 11(64비트), Steam의 Crimson Desert, DirectX 12 그래픽 카드, Microsoft Edge WebView2 Runtime(Windows 11과 최신 상태의 모든 Windows 10에 포함)이 필요합니다. 모드로 플레이하려면 게임의 bin64 폴더에 ASI 로더(예: Ultimate ASI Loader, 포함되지 않음)가 있어야 합니다. 플레이 모드와 실시간 미리보기에는 World Builder 플러그인이 추가로 사용되며, MetaHuman/Fab 패키지를 가져오려면 Unreal Engine이 필요합니다.

프로그래밍이나 3D 모델링을 알아야 하나요?

아니요. 오브젝트 이동, 아이템 수정, 퀘스트와 텍스트 편집 같은 대부분의 작업은 폼과 마우스로 처리합니다. 자체 모델에는 3D 파일만 있으면 되고 나머지는 어시스턴트가 처리합니다.

게임이 업데이트되면 어떻게 되나요?

CDKit이 새 게임 버전을 감지하고 영향을 받는 프로젝트를 보여 줍니다. 런타임이 다음 실행 때 업데이트된 게임에 맞춰 모드를 다시 빌드하므로 다시 설치할 필요가 없고, 변경 사항은 거의 모든 경우 그대로 유지됩니다.

모드를 공유할 수 있나요?

네. '모드 게시'는 모드를 하나의 .cdpkg 패키지와 모드 사이트용 ZIP으로 만듭니다. 다른 사람은 '모드 가져오기'로 추가하고, 끌어서 자신만의 로드 순서를 정하고, 충돌을 확인하며, 모드를 업데이트하거나 업데이트를 되돌릴 수 있습니다.

CDKit 없이도 플레이어가 내 모드를 쓸 수 있나요?

네. GitHub 릴리스에서 CDKit Runtime(cdkit.asi와 mods 폴더)을 내려받아 게임 폴더에 압축을 풀고, ASI 로더를 추가한 뒤 .cdpkg 파일을 bin64\CDKit\mods에 넣으면 됩니다.

CDKit은 어디서 받나요?

편집기가 같은 두 가지 에디션이 있습니다. GitHub 릴리스의 표준 에디션은 업데이트 기능이 내장되어 있고, Nexus Mods의 Nexus 에디션은 자체적으로 인터넷에 연결하지 않으며 Nexus 페이지를 통해 업데이트됩니다.
