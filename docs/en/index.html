How it works

From idea to in-game in three steps

Your work lives in a project folder. CDKit turns it into an extra package the game loads on top of its own data.

Create a project

Pick a folder and a name. Everything you change from now on is collected there – easy to back up, version and share.

Make your changes

Use the world editor, quest designer, item editor and assistants. Undo anything, preview it in 3D, test it with play mode.

Install with one click

Close the game, click Install, play. Changed your mind? Uninstall puts the game back exactly as it was.

Safe by design

Your game stays restorable

Mods are separate packages outside the game folder. CDKit's small runtime (cdkit.asi) shows them to the game while it runs – not a single original game file is changed. Uninstall takes them out at once, game updates and Steam's file check no longer remove your mods, and several mods load together with every conflict listed.

Questions

Good to know

Is CDKit free?

Yes. Download it, unpack it and start CDkit.exe – no account, no installer.

Will it break my game or my save games?

No original game file is changed. CDKit builds your mods into its own folder, and its runtime cdkit.asi (loaded by an ASI loader in bin64) shows them to the game while it runs. Uninstall takes everything out at once, and game updates or Steam's “Verify integrity of game files” no longer remove your mods. Play mode blocks saving, so your saves stay safe while testing.

What do I need?

Windows 10 or 11 (64-bit), Crimson Desert on Steam and a DirectX 12 graphics card. Play mode and live preview additionally use the World Builder plugin; importing MetaHuman/Fab packages needs Unreal Engine.

Do I need to know programming or 3D modelling?

No. Most tasks – moving objects, changing items, editing quests and texts – are done with forms and the mouse. For your own models you need a 3D file, the rest is handled by an assistant.

What happens when the game gets an update?

Steam resets the game's package list, so mods become inactive. Open your project in CDKit, click Build and Install – your changes carry over in almost all cases.

Can I share my mods?

Yes. Share your project folder; others open it in CDKit and click Install, and CDKit rebuilds it for their game version.
