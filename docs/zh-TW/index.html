你的遊戲始終 可以還原

模組與遊戲本身的檔案保持分離。CDKit 的小型執行階段（cdkit.asi，由 ASI 載入器載入）在遊戲啟動時建置你啟用的模組，並在遊戲執行時把它們提供給遊戲——不會修改任何一個原始遊戲檔案。在模組管理器中關閉的模組會在下次啟動時消失，多個模組可以依你自己的順序同時載入，並列出每一處衝突。

常見問題

你需要 瞭解的內容

CDKit 免費嗎？

是的。下載並解壓，然後運行 CDkit.exe ——無需賬號，也無需安裝程序。

它會損壞游戲或存檔嗎？

不會修改任何原始遊戲檔案。執行階段 cdkit.asi（由 bin64 中的 ASI 載入器載入）會在遊戲啟動時建置你啟用的模組並顯示載入畫面，然後在遊戲執行時把它們提供給遊戲。在模組管理器中選擇「停用此模組」或「停用所有模組」即可關閉它們，下次啟動時就會使用遊戲本身的檔案。遊玩模式會阻擋存檔，測試期間你的存檔保持安全。

我需要什麼？

Windows 10 或 11（64 位元）、Steam 版《赤血沙漠》、支援 DirectX 12 的顯示卡，以及 Microsoft Edge WebView2 Runtime（Windows 11 和所有保持更新的 Windows 10 均已內建）。要遊玩模組，遊戲的 bin64 資料夾中需要一個 ASI 載入器，例如 Ultimate ASI Loader（不隨附）。遊玩模式和即時預覽還會使用 World Builder 外掛程式；匯入 MetaHuman/Fab 封包需要 Unreal Engine。

需要會程式設計或 3D 建模嗎？

不需要。移動對象、修改物品、編輯任務和文本等大多數操作都可通過表單和鼠標完成。導入自制模型時只需準備 3D 文件，其餘步驟由助手處理。

游戲更新後會怎樣？

CDKit 會察覺新的遊戲版本，並顯示受影響的專案。執行階段會在下次啟動時針對更新後的遊戲重新建置你的模組——無需重新安裝，你的修改幾乎在所有情況下都能保留。

我可以分享自己的模組嗎？

可以。「發佈模組」會把你的模組寫成一個 .cdpkg 封包，並附帶一個用於模組網站的 ZIP。其他人用「匯入模組」加入它，拖曳模組排出自己的載入順序，檢查衝突，還可以更新模組或復原更新。

玩家沒有 CDKit 也能使用我的模組嗎？

可以。他們從 GitHub 發佈頁下載 CDKit Runtime（cdkit.asi 和一個 mods 資料夾），解壓縮到遊戲資料夾，加上一個 ASI 載入器，再把 .cdpkg 檔案放進 bin64\CDKit\mods。

在哪裡下載 CDKit？

共有兩個版本，編輯器完全相同：標準版來自 GitHub 發佈頁，內建自動更新；Nexus 版發佈在 Nexus Mods 上，它本身不建立任何網路連線，透過其 Nexus 頁面更新。
