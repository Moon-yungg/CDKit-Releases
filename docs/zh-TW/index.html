你需要 瞭解的內容

CDKit 免費嗎？

是的。下載並解壓，然後運行 CDkit.exe ——無需賬號，也無需安裝程序。

它會損壞游戲或存檔嗎？

不會修改任何原始遊戲檔案。CDKit 將你的模組建置到它自己的資料夾中，其執行階段 cdkit.asi（由 bin64 中的 ASI 載入器載入）在遊戲執行時把它們提供給遊戲。解除安裝即刻移除一切，遊戲更新或 Steam 的「驗證遊戲檔案的完整性」不再刪除你的模組。遊玩模式會阻擋存檔，測試期間你的存檔保持安全。

我需要什麼？

Windows 10 或 11（64 位）、Steam 版《赤血沙漠》以及支持 DirectX 12 的顯卡。游玩模式和實時預覽還會使用 World Builder 插件；導入 MetaHuman/Fab 包需要 Unreal Engine。

需要會程式設計或 3D 建模嗎？

不需要。移動對象、修改物品、編輯任務和文本等大多數操作都可通過表單和鼠標完成。導入自制模型時只需準備 3D 文件，其餘步驟由助手處理。

游戲更新後會怎樣？

Steam 會重置游戲的數據包列表，因此模組會暫時失效。在 CDKit 中打開項目，點擊 Build 和 Install——絕大多數情況下你的修改都可以繼續使用。

我可以分享自己的模組嗎？

可以。分享你的項目文件夾；其他人在 CDKit 中打開並點擊 Install，CDKit 會針對他們的游戲版本重新構建。
