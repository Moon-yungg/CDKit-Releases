工作原理

从创意到游戏内 只需三步

你的作品保存在项目文件夹中。CDKit 的运行时（cdkit.asi）会在游戏启动时构建你启用的模组，并将它们叠加在游戏自身的数据之上加载。

创建项目

选择文件夹和名称。从此之后的所有修改都会集中保存在这里，便于备份、版本管理和分享。

进行修改

使用世界编辑器、任务设计器、物品编辑器和各类助手。任何操作都可撤销，可在 3D 中预览，也可通过游玩模式测试。

游玩与分享

启动游戏：运行时会在加载画面后构建你启用的模组。在模组管理器中关闭某个模组，或把它发布为一个包供其他玩家使用。

从设计上保证安全

你的游戏始终 可以还原

模组与游戏自身的文件保持分离。CDKit 的小型运行时（cdkit.asi，由 ASI 加载器加载）在游戏启动时构建你启用的模组，并在游戏运行时把它们提供给游戏——不会修改任何一个原始游戏文件。在模组管理器中关闭的模组会在下次启动时消失，多个模组可以按你自己的顺序同时加载，并列出每一处冲突。

常见问题

你需要 了解的内容

CDKit 免费吗？

是的。下载并解压，然后运行 CDkit.exe ——无需账号，也无需安装程序。

它会损坏游戏或存档吗？

不会修改任何原始游戏文件。运行时 cdkit.asi（由 bin64 中的 ASI 加载器加载）会在游戏启动时构建你启用的模组并显示加载画面，然后在游戏运行时把它们提供给游戏。在模组管理器中选择“禁用此模组”或“禁用所有模组”即可关闭它们，下次启动时就会使用游戏自身的文件。游玩模式会阻止存档，测试期间你的存档保持安全。

我需要什么？

Windows 10 或 11（64 位）、Steam 版《红色沙漠》、支持 DirectX 12 的显卡，以及 Microsoft Edge WebView2 Runtime（Windows 11 和所有保持更新的 Windows 10 均已自带）。要游玩模组，游戏的 bin64 文件夹中需要一个 ASI 加载器，例如 Ultimate ASI Loader（不随附）。游玩模式和实时预览还会使用 World Builder 插件；导入 MetaHuman/Fab 包需要 Unreal Engine。

需要会编程或 3D 建模吗？

不需要。移动对象、修改物品、编辑任务和文本等大多数操作都可通过表单和鼠标完成。导入自制模型时只需准备 3D 文件，其余步骤由助手处理。

游戏更新后会怎样？

CDKit 会察觉新的游戏版本，并显示受影响的项目。运行时会在下次启动时针对更新后的游戏重新构建你的模组——无需重新安装，你的修改几乎在所有情况下都能保留。

我可以分享自己的模组吗？

可以。“发布模组”会把你的模组写成一个 .cdpkg 包，并附带一个用于模组网站的 ZIP。其他人用“导入模组”添加它，拖动模组排出自己的加载顺序，检查冲突，还可以更新模组或撤销更新。

玩家没有 CDKit 也能使用我的模组吗？

可以。他们从 GitHub 发布页下载 CDKit Runtime（cdkit.asi 和一个 mods 文件夹），解压到游戏文件夹，加上一个 ASI 加载器，再把 .cdpkg 文件放进 bin64\CDKit\mods。

在哪里下载 CDKit？

共有两个版本，编辑器完全相同：标准版来自 GitHub 发布页，内置自动更新；Nexus 版发布在 Nexus Mods 上，它自身不建立任何网络连接，通过其 Nexus 页面更新。
